# TXT Preview

## Objetivo

Mantener una aplicación WinForms para editar, transformar, previsualizar y leer contenido Markdown con asistencia de Groq.

## Alcance actual

- Edición y vista previa Markdown.
- Consultas, resumen, corrección y traducción con IA.
- Lectura mediante Windows Speech o Edge TTS.
- Controles de reproducción, velocidad y resaltado sincronizado.
- Exportación a PDF y MP3.

## Restricciones

- Las credenciales deben permanecer fuera del repositorio.
- Los cambios funcionales deben actualizar los artefactos SDD.
