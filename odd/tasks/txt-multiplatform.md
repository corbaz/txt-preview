# TXT Preview multiplatform (Windows + macOS)

App conversion from Windows-only PowerShell/WinForms to a cross-platform Python + pywebview application with identical behavior on Windows and macOS, per-platform installers, a dependency doctor, and a git-pull update workflow.

## Specs

- S1: "la idea es converti a la app en multiplataforma" — the app must work identically on Windows and macOS.
- S2: "que yo trabaje todo aca en windows pero ue la app este preparada para que la clone la mac y funciones identica en la mac" — development happens on Windows; a Mac user clones the repo and runs the same app with identical behavior.
- S3: "cada uno tenga su instalador en el radme explicado para el usurio o una ia para que le instale todo con su doctor si le falta algo" — README documents per-platform installers; a doctor checks and installs missing dependencies (git, Python, edge-tts, ffmpeg, WebView2 runtime), usable by a human or by an AI agent.
- S4: "Luego si yo hago un cambio en windows debe quedar compatible para la Mac asi el otro usuario en su mac lo actualiza con un pull" — every change pushed from Windows must stay Mac-compatible; the Mac user updates with `git pull`.
- S5 (decision): stack is **Python + pywebview** (native WebView2 on Windows / WKWebView on macOS; HTML/CSS/JS shared).
- S6 (decision): TTS is **Edge voices only** (`edge-tts` on both platforms); `System.Speech`/SAPI is dropped.
- S7: the existing PowerShell/WinForms app (`txt.ps1`) stays in the repo until parity is declared; the new app lives under `app/`.
- S8: "dejar botoneras tal cual original en bottom y todos los mismo botones de antes y misma ui y UX siempre arrancar maximizado" — the cross-platform app must preserve the original bottom control deck, every prior button/control, the same UI/UX and always start maximized.
- S9: "los botones no están bien distribuidos como en el original. Falta que, cuando Consultar IA o Resumir IA, tengan un spinner hasta recibir la respuesta. No se puede cambiar de modelos en la página principal." — center/distribute the complete bottom rows like the supplied original, show pending-request work feedback, and load/enable the main-page model selector.
- S10: "La vista previa tiene errores, como si no hubiese saltos de línea, que era todo muy pegado, líneas contralíneas. En el editor están esos espacios. Los spinners están en los botones. Queda muy mal. Deberían estar en la mitad de la pantalla, más grande, dando apariencia de trabajo. Adjunto la imagen donde la velocidad de lectura del switch tiene un error de UI." — preserve editor paragraph/line spacing in Preview, replace button spinners with one large centered work overlay, and keep slider fill aligned with its thumb from first render.
- S11: "los spinner no giran como un gif quedan quietos. Consulta AI repite la pregunta en en la respuesta no investiga . Los modelos propuesto por Groq deben ser chequeados con sus propiedades si son de vision si puened navegar  etc como se hacia en la app. Resumir anda bien" — keep the central spinner visibly rotating, make Consultar use web research only with a verified web-capable model and never echo the question, and restore live selected-model capability badges/gates from the Groq catalog without changing Resumir.
- S12: "Cuando empieza a reproducir el sonido Por ejemplo, en 1 X. Cuando comienza la lectura. Cambio la velocidad. Haciendo 5 X Salen dos voces. Una continua leyendo. La otra, la segunda velocida 2)Cerré la aplicaciónY el audio sigue reproduciéndose. 3) vista previa. Si hago clic. El audio comienza a lerr no porque yo haya apretado play" — a speed change during playback must fully replace the single voice (never overlap), closing the app must stop all audio, and clicking preview words must only act during an active reading, never start one by itself.
- S13: "si play mando un audio en x 1 y muvo 0,5 y pongo repetir repite el audio a 1 y desconoce 0,5" — Repetir must honor the speed slider value current at the moment it is pressed (or changed during a repetition), never the speed the audio was generated with. - S17: macOS Python 3.14 reports `ssl.SSLCertVerificationError: Basic Constraints of CA cert not marked critical` from Groq startup model loading, while Doctor says Edge voices cannot be queried. — use the native macOS Keychain trust store via truststore for the desktop app and Edge TTS subprocesses, never disable certificate verification; wrap TLS/network failures into controlled messages/fallbacks; update Doctor/install dependencies, VERSION/CHANGELOG, and push origin/main.
- S18: "continua en mac las funciones no andan casi ninuguna solo abre y en windows y mac consultar no hace investigacion" — verify every public UI action through the real pywebview bridge on macOS-compatible paths; repair platform-specific failures instead of accepting window startup as success; make Consultar perform real researched web search on every supported platform/model path and show controlled errors when research is unavailable.
